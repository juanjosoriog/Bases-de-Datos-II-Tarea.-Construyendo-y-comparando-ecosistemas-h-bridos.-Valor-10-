# Arquitectura Híbrida de Bases de Datos (PostgreSQL + MongoDB)

Este repositorio contiene los scripts, datos de prueba y métricas comparativas de una arquitectura de persistencia híbrida (ACID + BASE).

### Estructura del Proyecto
- `01-postgresql-acid/`: Scripts DDL, inserción de datos maestros y consultas relacionales con métricas `EXPLAIN ANALYZE`.
- `02-mongodb-base/`: Validación de esquema JSON, script de ingesta masiva automatizada (`bulkWrite` de 100,000 eventos) y pipelines de agregación optimizados.
- `03-evidencias-metricas/`: Resultados cuantitativos de benchmarks
